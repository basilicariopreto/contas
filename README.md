# 💰 Controle de Contas

Aplicação web para controle de receitas e despesas mensais — sem servidor, sem banco de dados, tudo roda no navegador.

## ✨ Funcionalidades

- **Receitas** — fixas e variáveis, com categoria
- **Despesas Fixas** — com dia de vencimento e alerta de atraso
- **Despesas Variáveis** — lançamentos do mês com data
- **Marcar como pago** — controle visual de quitação
- **Edição completa** — modal para editar qualquer lançamento
- **Gráficos** — distribuição de despesas por categoria + receitas × despesas
- **KPIs** — resumo de receitas, despesas, saldo e % de contas pagas
- **Exportar CSV** — baixa todos os lançamentos do mês
- **Dark mode** — alterna entre tema claro e escuro
- **Navegação por mês/ano** — cada mês tem seus dados independentes
- **100% offline** — dados salvos no `localStorage` do navegador

## 🚀 Acessar online

Acesse em: **https://basilicariopreto.github.io/contas**

## 🖥️ Rodar localmente

Basta abrir o arquivo `index.html` no navegador — não precisa de servidor.
